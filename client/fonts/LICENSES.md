# Fonts

| File | Font | Used for |
|---|---|---|
| `Cinzel.ttf` | Cinzel (variable) | titles and civilisation names |
| `Nunito.ttf` | Nunito (variable) | interface text |
| `emblems.ttf` | Noto Serif SC Bold, cut down to the characters in `emblems.txt` | civilisation badges (秦, 楚…); rebuild with `scripts/build_emblem_font.py` |
